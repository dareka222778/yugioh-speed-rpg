# Coordenação de desenvolvimento
A referência compartilhada é feat/rea-engine-recovery-20261026, coordination/state.json. Leia diretamente do HEAD remoto antes de editar e novamente antes de publicar. Para adquirir, publique estado active, dono, escopo e ID únicos por fast-forward a partir do HEAD lido. Uma corrida perdida exige reler e reavaliar; nunca force o push. Um dono ativo não perde o controle por tempo decorrido. Work tem prioridade: registre o pedido de transferência sem alterar o dono, aguarde checkpoint e liberação para escopos conflitantes. Antes de cada bloco e após os testes, atualize a atividade e verifique pedidos. Ao terminar, publique o checkpoint em coordination/runs, libere o controle e registre a próxima execução somente quando confirmada pelo agendador. Nenhum registro autoriza merge, deploy ou concessão de inventário.
